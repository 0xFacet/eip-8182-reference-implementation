EIP-8182 pool-proof, in the browser

Runs the EIP-8182 reference pool circuit end-to-end (witness gen + Groth16 prove) using snarkjs WASM. No native code, no app install.

What this actually does

Click Run and the browser will:

1. Load a pre-built witness input (12 KB) — the same worst-case witness this repo's tests use, with all three outputs real and all three output bindings locked.

2. Run snarkjs's WASM witness generator (332 KB) against pool.wasm to produce the witness binary (~1.3 MB in memory).

3. Run snarkjs's WASM Groth16 prover against the proving key (pool_final.zkey, 27 MB) to produce a 256-byte BN254 Groth16 proof + 19 public-input field elements.

4. Verify the proof locally against pool_vkey.json as a sanity check that the WASM stack actually produced a valid proof.

All four steps are timed separately. The headline number is the prove step — that's what dominates wallet UX on phones. Witness gen is small but still part of the user-facing latency.

This is the slow path for proving: pure WASM, single-threaded. A wallet would ship native rapidsnark for ~10× speedup over the numbers you see here.

About: reference impl for EIP-8182 Native Shielded Pool (Groth16/BN254 split-proof variant). 42,959 constraints, 19 public inputs, 26 MB zkey. Source: circuits/pool/pool.circom in the reference impl repo.
